KAKAO MAP API

카카오맵 1차 기능 테스트

주소/좌표 변환과 장소 검색을 먼저 연결합니다. 정적 지도와 경로 조회는 다음 패치에서 이어서 연결합니다.

메인으로
📍

주소 → 좌표 변환

도로명/지번 주소를 입력하면 좌표 x, y를 조회합니다.

🧭

좌표 → 주소 변환

WGS84 좌표 x, y를 입력하면 행정 주소를 조회합니다.

🔎

장소 검색

키워드로 장소를 검색합니다. 좌표를 함께 넣으면 주변 검색과 거리순 정렬이 가능합니다.

🗺️

정적 지도 조회

2차 패치에서 백엔드 이미지 프록시 방식으로 연결할 예정입니다.

🚗

경로 조회

3차 패치에서 출발지/도착지 좌표 기반 경로 조회를 연결할 예정입니다.
