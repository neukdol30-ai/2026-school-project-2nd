KAKAO MAP API

카카오맵 기능 테스트

주소/좌표 변환, 장소 검색, 정적 지도 조회를 테스트합니다. 경로 조회는 다음 패치에서 이어서 연결합니다.

메인으로
📍

주소 → 좌표 변환

도로명/지번 주소를 입력하면 좌표 x, y를 조회합니다.

🧭

좌표 → 주소 변환

WGS84 좌표 x, y를 입력하면 행정 주소를 조회합니다.

🔎

장소 검색

키워드로 장소를 검색합니다. 검색 결과의 좌표로 정적 지도도 바로 확인할 수 있습니다.

🗺️

정적 지도 조회

좌표를 기준으로 이미지 지도를 조회합니다. REST API 키 보호를 위해 서버 프록시로 이미지를 내려받습니다.

🚗

경로 조회

3차 패치에서 출발지/도착지 좌표 기반 경로 조회를 연결할 예정입니다.
