KAKAO MAP API

카카오맵 기능 테스트

주소/좌표 변환, 장소 검색, 정적 지도 조회, 경로 조회를 테스트합니다.

메인으로
📍

주소 → 좌표 변환

도로명/지번 주소를 입력하면 좌표 x, y를 조회합니다.

🧭

좌표 → 주소 변환

WGS84 좌표 x, y를 입력하면 행정 주소를 조회합니다.

🔎

장소 검색

검색 결과의 좌표를 출발지/도착지로 바로 설정할 수 있습니다.

🗺️

정적 지도 조회

좌표를 기준으로 이미지 지도를 조회합니다.

🚗

경로 조회

출발지와 도착지 좌표를 입력해 대중교통, 도보, 자전거 경로를 조회합니다.

장소 검색 결과에서 출발지로 설정 / 도착지로 설정 버튼을 누르면 좌표가 자동 입력됩니다.
